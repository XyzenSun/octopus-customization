# internal/op

本目录封装资源 CRUD, 缓存, 用户与两步验证, 备份和运行数据聚合. cache.go 编排启动加载与退出保存, 其余文件按资源划分.

普通 CRUD 沿用数据库写入成功后更新缓存的方式. Key 运行状态, 统计和日志继续使用各自的内存聚合路径, 不把所有写操作套成同一顺序. 修改用户凭证时核对缓存与数据库的失败处理, 当前用户写入会先修改缓存.

修改日志行为时读取 internal/op/log.go 和 internal/model/setting.go, 核对保留开关, 刷写阈值与内存容量的配合. 日志达到刷写阈值或采用实时写入时会同步写库, 不能假设调用只入异步队列.

新增需要退出持久化的内存数据时读取 internal/op/cache.go, 把保存操作纳入既有退出流程. 调整统计或 Key 聚合时核对各自的锁, 快照与写库失败后的待保存标记恢复, 保持缓存与持久化协同.
